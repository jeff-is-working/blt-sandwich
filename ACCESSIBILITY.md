# Accessibility

The page aims to meet WCAG 2.2 Level AA.

- Every map tile shows the state, price and count as text, so color is never the only signal.
- The map and chart have table equivalents on the same page.
- Everything works by keyboard, with a visible focus outline. Map tiles open with Enter or Space.
- The page respects reduced-motion settings and works at narrow widths and 200% zoom.
- Checked with axe-core (0 violations) and a keyboard-only pass.

Found a problem? [Open an accessibility issue](https://github.com/jeff-is-working/blt-sandwich/issues/new?template=accessibility.md).
